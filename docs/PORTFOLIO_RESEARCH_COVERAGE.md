# 组合研究覆盖与指数联接同类比较

v0.43.0 复用 D1 当前结构化研究/不可变基线、公开证据及 D2 版本表，无新账本或研究系统、无数据库迁移。

## 使用

“复核我的组合，哪些最值得进一步研究？”对应 `investor-assistant portfolio-research`，逐基金详情 `portfolio-research --code <基金代码> --details`。

Core GET `/v1/portfolio-research-coverage` 使用已有组合与账户，动态读取正份额持仓；默认逐持仓一行，详情按同基金/同类原因合并并保留全部底层证据。客户端只传递 Core 结果。查询不采集、不归档、不创建 D1 观察点/待办，不处理或批准任何历史记录。

分类依据是归档正式产品文件中的引用及类型/投资范围/适配比较方法，独立于 CORE/SATELLITE、批准映射及投资资格。转载披露标明原站未核验，不能由基金名称或渠道限额推断。缺少类型证据的新持仓显示未知并要求补产品概要，持仓变动无需修改代码。

四类工作事项为已有发现复核、比较前补证、用户配置决定及资料维护，不打分或排序基金。同窗口 D1 与 D2 值并列，注明版本/方法；两位披露舍入与日序列浮点误差只作细节，不制造实质冲突。原有研究警告不清除。查询日、各方法数据截止、归档日期分别保留；归档未变不代表最新情况未变。

## 第二类方法

`investor-assistant peers --anchor 022463` / `--details` 读取同指数联接研究；原003096医疗比较及验证入口语义不变。

先按正式规则选择022463富国和022424广发两独立基金的人民币A份额：同为中证A500 ETF联接，目标ETF分别为563220/563800。不重复计算A/C/Y份额，不把目标ETF、指数增强或普通指数基金与联接直接混排。广发2024-11-18由普通指数转为联接，该日前历史排除；富国成立2024-11-11。小样本非全市场筛选。

中证官方事实表确认价格指数000510、全收益000510CNY010、净收益000510CNY020。分别保存准确目标指数与官方“价格指数95%+税后活期5%”比较基准。日历取CSI实际交易日，不能作为申购开放日历。共同历史454个交易日，最新完整共同净值2026-09-28；窗口为2025全年/上下半年、2026上半年、当年起点至共同截止、6月末至共同截止，均先于计算确定。

两只准确份额官方单位净值与完整查询分红记录均已取得，接口零分红记录仍是单源观察。总回报按每日现金分红再投资计算，净值内持续费用不再扣；个人申赎费用未知。最大回撤列为“基金最大回撤（共同交易日）”。无缺日填补或其他份额拼接。

目标价格指数诊断：跟踪差异=基金累计总收益－准确目标价格指数累计收益(百分点)；跟踪误差=日收益差的样本标准差(ddof=1)×sqrt(252)，显示频率/样本/年化因子。价格指数不含股息，属于明确口径的目标指数诊断；**不是95/5官方复合基准重建或合同跟踪目标达标判断**。现金腿税后利率历史/计息规则仍缺失，正式复合基准指标未计算。身份/变体/币种不匹配或任一共同日缺失则阻断对应指标。

2026中报显示两只联接目标ETF比例、现金与直接持股不同；总资产与净资产分母分开，不将期末当期间平均，不把差额归因于选股Alpha。约定管理费0.15%和托管费0.05%针对扣除目标ETF后的相应基数，不重复叠加扣费；历史费率全链和个人渠道费用仍未核实。
