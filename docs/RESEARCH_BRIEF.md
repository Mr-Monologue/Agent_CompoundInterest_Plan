# 主动取数的投资研究简报

`research-brief` 在用户明确请求研究时读取公开行情，计算区间与历史比较，并生成研究简报。它替代手工准备行情JSON的步骤；仍不等于完成估值、盈利分析或交易决策。

```sh
investor-assistant research-brief --start 2026-11-13 --end 2026-11-17
investor-assistant research-brief --market-only --fund 022463 --fund 000032 --fund 002340 --fund 040046 --start 2026-11-13 --end 2026-11-17
investor-assistant --json research-brief --market-only --start 2026-11-13 --end 2026-11-17
```

默认先只读解析现有Core上下文和持仓，按实际持仓代码查询基金。Core不可达时继续公开市场研究，明确没有持仓连接，不把关注清单当作持仓。`--market-only`完全跳过Core。未指定起点时使用结束日所在周的上周五；没有该日数据则报告缺端点，不静默改日期。当天的收盘研究在上海时间16:00前拒绝执行，避免把盘中价格当收盘。

## 数据与计算

- 三个主要指数：东方财富历史行情，新浪作为第二渠道及失败替代。请求有超时、响应大小限制；不执行远程代码。一个渠道或一只基金失败不阻断其他研究。
- 基金：东方财富单位净值，保留实际净值日期，明确不是含分红总收益或个人收益。
- 比较：精确指定端点；最新相邻观测涨跌；20/60个观测间隔变化；最近60个观测收盘高点回撤；单次以及同长度区间累计波动绝对值的历史百分位。
- 百分位使用此前至多252个样本，至少120个才输出；当前评估区间不进入历史样本。多日窗口可重叠，因此不是独立样本显著性或上涨概率。交易日历未独立验证，字段称“观测间隔”，不能伪称经过补齐的交易日序列。
- 指数按0.011点容差比较渠道收盘（适应两位/三位小数舍入）。冲突保留并排除总体观点和异常分位；渠道一致不自动证明独立上游。基金仍为单源WARNING。
- JSON保留来源URL、读取时间、响应哈希、选定历史序列和错误。历史日期请求是今日数据的事后回放，不能作当时可知的前瞻记录。

## 输出如何使用

先看观点，再看累计变化与单日变化是否一致，并查看关注基金的直接证据。简报比较维持安排、暂缓新增和调整标的的代价；没有估值/盈利证据时不因跌幅大生成加仓承诺。自动文本是确定性的受限价格分析，不能宣称已经完成基本面研究、行业穿透或个性化资金配置。

代码不更新净值库、不更改财务事实、不冻结计划、不启动调度。JSON输出可能包含Core真实持仓原文，必须保存在用户私有位置，不提交公共仓库。
