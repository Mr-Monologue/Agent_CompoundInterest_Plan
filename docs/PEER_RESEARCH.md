## 日期、计算与证据

先定窗口：2023（2022-12-30至2023-12-29）、2024（至2024-12-31）、2025（至2025-12-31）、2026H1（至2026-06-30），后一窗口以前一终点为基点。

使用已归档 CSI 000933 官方日序列的交易日期作为共同网格（不是新的收益基准映射）。两只准确 C 份额官方日净值各847条，网格844日期；额外非交易日记录保留原始档案，不进入共同交易日回撤。逐日净值加当日每份现金红利，再除前一净值连乘；分红复投口径明确。累计净值不是复权值。缺端点、缺任意网格日、分红覆盖未证、份额历史不足或来源冲突直接阻断该窗口，不插值、不填零。持续费用已经反映净值，不重复扣减。申赎费、持有期和渠道优惠未知单列。

最大回撤为财富路径相对此前峰值的最小跌幅，显示“基金最大回撤（共同交易日）”，不是累计亏损。报告收益单独保留为管理人披露，不能冒充路径重建。半年度报告收益与重算在0.005个百分点披露舍入范围内核对；该容差是显示验证精度，不是投资阈值。

证据复用 SourceArchive：官方来源URL、发布日期、数据日期、真实获取时间、全文或引用、原文件SHA256、结构化事实。日序列及精确日历与研究输入一并保存；原始PDF/JSON留本机研究档案。详情可回读全部来源与输入，可用固定计算版本重新计算。官方单源警告保留；同一管理人报告交叉核对不称独立第二来源。

当前资料事后比较不是历史选基回测。拒绝未来发布日期/数据；历史查询只返回该时点已归档版本。历史产品条款完整变更链未齐，不能宣称当前条件在所有过去日期都成立。新任经理共同管理不能倒推其对任职前表现负责。

## API与日常入口

- “比较003096与同类候选” → `investor-assistant peers --anchor 003096`
- “查看广发医疗保健的比较详情” → `investor-assistant peers --anchor 003096 --code 009163 --details`
- `GET /v1/peer-research?anchor_code=003096`；可选 cohort_key、run_id、as_of、instrument_code、view=DETAIL。
- 公共研究发布：`POST /v1/peer-research-runs`，完整 PeerStudy + 固定幂等请求 + expected_previous_version。只能追加独立研究表。同内容重放返回原版本；同键改内容冲突，版本漂移必须先回读。响应丢失先 GET 核对，不盲目改键重发。
- 查询只读且不刷新；默认显示共同研究截止、归档日、查询日及本次未获取新证据。Core 生成表和解释，客户端不重新计算。
