# 投资价值优先：研究交付契约

这是研究入口的产品行为改革，不是投资策略、资金比例或模型晋级批准。具体阶段状态和结束条件只维护 LAUNCH_CHECKLIST.md 当前入口。

## 产品目标

用户买的是判断质量与时间节省：理解正在发生什么，辨别与自己有关的机会和风险，比较可选行动，并知道什么证据会改变判断。记账、核验和治理是基础设施，不能独立作为投资价值验收。

原始设计核对发现：仓库附件为 architecture-v1.7.0-draft.2；用户保存的原始方案为 draft.5。后者强调分资产的环境判断、工具选择与持有理由检验。不能据此自动激活草案策略，也不能用全局“市场季节”统辖债券、A股、海外权益和主动基金。

## 默认交付：投资判断简报

当用户问市场变化、机会、风险、持仓理由或资金安排，Agent 应主动完成研究，不把接口清单、旧观察或警告汇总作为答案。使用以下次序，篇幅随问题缩放：

1. **当前判断**：一至三句可被反驳的判断，明确支持程度和时间范围。证据不足时，把已能判断的部分说清楚；不能只说“继续观察”。
2. **关键证据与反证**：同时给支持和反对依据；明确公开事实、Core计算、Agent推断。来源转载链不能当独立交叉验证。旧归档未变化不代表今天研究已更新。
3. **与投资的关系**：用明确基准、最新可得持仓/行业暴露说明关联；未知部分局部隔离，不按基金名称推断全部暴露，不冒充精确收益归因。
4. **选择比较**：至少比较维持当前安排与一个有关替代方案（例如暂缓新增、分批、换同指数工具、检查持有理由）。分别说明受益条件、代价、主要失败情形；没有依据时可以明确暂不支持改变，而非制造操作。
5. **改变判断的条件**：具体可获取的证据、指标和复核时点/事件；未经批准的新阈值只能作为研究假设，不能触发交易。不要伪造先前预测、事前理由或事后胜率。

纯“查持仓/查账”请求仍遵循 Core 原文展示契约。研究请求中，Core 原文作为单独事实区块原样保留，另外给出清楚标识的研究分析；不得把 EXACT_TEXT 扩展为禁止回答用户明确提出的研究问题。Agent 不改写 Core 数字、不填造缺失的金融事实。没有生产连接时明确只使用已获证据，不能声称重读生产。

普通公开研究、论据比较不以复杂评分模型晋级为前提；SHADOW 模型结果仍不得包装为获批信号。建议、策略变更、批准、外部成交和账本记录必须继续分开。

## 可重复计算入口

```sh
investor-assistant market-observation examples/research/market-week-replay.json
investor-assistant --json market-observation examples/research/market-week-replay.json
```

此入口离线读取带来源的 JSON：观察截止日期、区间起止、前一交易日、指数口径/币种、逐日点位、发布时间与查阅日期。只计算指定端点；不能用下周一或最新净值替换缺失端点。数据结构由 `investor_core.market_observation.ObservationPacket` 定义。

当前版本是日级、收盘后/事后回放工具，不支持盘中可用性回测或 vintage 追踪；拒绝带时间的截止值。输入时应标明不同市场日历，先核实前一交易日。工具不独立核实来源、日历，不联网、不入库，不计算异常概率、基金归因或投资建议。所有输出仍 UNVERIFIED；正确计算不能提升证据等级。

示例为公开市场回放，不含用户持仓。2026-11-09取得的资料不能冒充11月6日事前存档。三个指数不能替代“全A股”，也不能替代 A500。

## 回放示范：判断如何帮助用户

2026-11-02至11-06，三个主要指数区间上涨，而最后交易日均回落，创业板末日跌幅最大。**有证据支持“最后交易日风险偏好转弱”的描述，但没有证据支持“整周全面下跌”或“已进入历史异常状态”。** “风险偏好”是研究解释，不是已证实的因果。

反方解释：这也可能是上涨后的短期回吐。只有三个价格序列，不能确定资金流向、基本面转折或下跌持续性。没有长期分布，不输出异常分位。

选择比较：仅因这一天急跌就退出，可能减小继续下跌损失，也可能在短期回吐后错失反弹并增加摩擦；维持既有纪律，可避免临时追涨杀跌，但仍承担继续回撤。**本组证据本身不支持临时加仓，也不足以单独支持清仓。** 真正需要补的决定性证据是持有标的本身的表现、暴露与持有理由是否变化，不是再增加泛化风险提示。

下一次研究应比较随后完整交易日的市场广度及相关持有标的变化，区分单日扰动和持续弱化；这只是研究复核条件，未创建自动任务或交易阈值。这个示例验证论证方式，不证明策略有效或预测正确。

## 成效的证据

工程测试只证明软件行为；报告完整只证明交付形式；二者都不能证明投资优势。研究价值要用前瞻记录检验：当时知道什么、判断/替代方案/反证是什么、随后哪些证据支持或推翻判断、节省了哪些人工核查、是否帮助解决实际选择。

策略收益比较需按真实可执行规则比较不加判断的定投与候选方案，纳入费用、限购、确认延迟和未投现金；同时看回撤、恢复时间、换手与错误操作。两周交易或一篇周报都不足以证明收益能力。避免选择性展示成功案例，不能用测试数、接口数或“零风险命中”代替成效。
