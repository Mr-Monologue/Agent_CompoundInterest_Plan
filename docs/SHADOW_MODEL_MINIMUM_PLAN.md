# C/D最小实施方案与E衔接条件（方案，未启动模型）

依据候选 architecture-v1.7.0-draft.2 §8—10、§19—23。2026-10-08起已授权实现影子证据与治理设施，当前进度只见LAUNCH_CHECKLIST末尾；数值方法尚待评审，无模型激活、概率、排名或金额变更。现行策略v1.6继续。软件、策略、模型分别版本化。

## C：市场/结构四季的最小可验证闭环

1. 先做一个用户明确选择的研究作用域，不将其结论推广到其他市场、区域、行业或风格。作用域选择单独登记；不默认把医疗当作全市场。
2. 复用证据归档，新增通用模型注册、输入清单、观察及验证记录（原文§8.6）。输入保存发布/可知时点、数据日、获取时点、版本、指纹和缺口。当前基金/指数序列不能替代时点一致的盈利修正、估值、政策流动性和市场结构数据。
3. 首版接口建议：读取模型版本、提交隔离影子输入、读取观察/验证。注册只进入DRAFT/SHADOW；生产计划不读取模型输出。缺关键输入返回UNKNOWN/INSUFFICIENT_DATA，概率留空，不让语言模型补概率。
4. 在隔离回放中逐时点构造可知信息，晚发布/事后修订不能泄漏到过去。参数、入退条件、持续/连续期、TRANSITION及低置信处理均来自版本化评审配置；方案不代填数值。
5. 验收：同版本同指纹确定性重放；未来数据和错作用域阻断；修订保留旧观察；缺失与低质量明确；任何影子结果下现行金额逐项相同。另提交跨市场阶段回放与样本外观察设计，观察期尚未预先批准或执行。

外部依赖：可追溯、具可知时间的数据覆盖；模型方法及参数的评审依据；用户选定首个作用域。数据不足时只交付清单和UNKNOWN，不声称已完成四季预测。

## D：研究候选与相对表现最小闭环

1. 先提交并确认候选范围与产品约束（市场、产品、主动/QDII、历史、规模、流动性、费用、覆盖）。不硬编码Top20或赛道配额；未确认范围只读现有持仓，不声称完成候选筛选。
2. 复用现有watchlist、MAPER、论点版本和基准。输出普读覆盖矩阵→产品/数据/身份/基准/约束硬过滤→可精读清单；缺数据不能默认过滤通过或自动评分为零。
3. 有足够证据后才提出版本化评分权重及方法，先SHADOW。记录每个入选/淘汰理由、输入指纹、费用、确认延迟和可执行限额；无足够数据不生成可比排名。
4. 相对表现继续区分管理人公布路径与成分独立重建，使用历史生效基准和同收益口径。研究映射批准不等于STRONG动作代理；超额不是选股Alpha，共同波动不等于因果归因。
5. 假想替换只形成研究记录；连续领先、领先幅度、最短持有期、费用和论点削弱等条件须评审后版本化。单期名次不触发真实动作。
6. 验收：未批准范围/映射和缺数据明确阻断动作型诊断；同输入可重放；历史规则不回写；排名稳定/成本/延迟敏感性有真实输入；所有影子输出不改变当前计划金额、持仓或账本。未经证实的归因返回INSUFFICIENT_DATA。

外部依赖：其余研究映射及代理适用性确认、独立净值/指数/分红/汇率/现金口径、时点化产品资料、候选范围及规则评审。已完成的基准设施不重建；单基金缺口不阻断其他覆盖记录。

## E：只在条件齐备后提出晋级，不随软件发布激活

- SHADOW→ADVISORY：覆盖/质量、无未来泄漏、版本化参数、输出稳定、解释与当前策略无冲突，并有具体用户确认。
- ADVISORY→ACTIVE：事先约定的样本外观察完成；对照无模型基线；计入申赎费用、确认延迟和限额；检查路径最大回撤、换手与错误动作；跨阶段压力测试；独立评审报告；具体策略草稿与用户确认。不得SHADOW直接ACTIVE。
- 先集中解决现行v1.6与候选v1.7差异：WARNING参与金额及准入、无合格卫星资金保留/批准备用顺序、机会预算来源、研究论点准入与风险规则。未知不能用默认值补齐，批准研究论点不批准这些资金规则。
- 预先测试质量下降、代理失效、模型漂移/稳定性异常、实际执行偏离及用户暂停时的降级；保留全部历史。降级不抹除已发生财务事实。
- 真实通知和运行场景、账户执行约束及第一笔真实投资闭环仍独立验收。批准C/D工程方案不等于批准E激活，也不授权真实买卖。

### C：规则分数、四季与稳定机制

为避免“便宜=冬季/利好=夏季”的混淆，将价格位置与非价格改善分开：

- `X=0.70×P−0.30×V`：周期位置轴，高为上涨/偏贵、低为下跌/偏便宜。
- `Y=0.40×F+0.30×L+0.30×B`：景气/流动性/广度轴，高为改善。
- 展示分数`position_score=50×(X+1)`、`improvement_score=50×(Y+1)`，不加总成“推荐投资分”。V/F/L/B/P全部必需；缺一则无新候选，旧稳定态只作last_valid历史，不当今日结论。
- 进入象限阈值绝对值0.20：X≤−0.20,Y≥0.20为SPRING；X≥0.20,Y≥0.20为SUMMER；X≥0.20,Y≤−0.20为AUTUMN；X≤−0.20,Y≤−0.20为WINTER；其余TRANSITION。等号按上式闭区间，无重叠。
