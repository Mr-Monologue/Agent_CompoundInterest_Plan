# 基准与相对表现研究（v0.36.0）

本模块独立于策略估值代理。官方比较基准、候选诊断映射和批准的研究映射分别表达；官方披露不自动成为 STRONG 代理。研究批准不改变风险扫描、资金配置或策略版本。

## 使用与治理

- `investor-assistant benchmark --code <基金代码>`：读取默认组合的版本、区间、局限及已保存研究；只读。
- `POST /v1/benchmark-mapping-drafts`：保存官方披露和诊断映射，按基金追加版本；引用已归档同基金证据。固定请求键与预期版本防重复/覆盖。
- `POST /v1/benchmark-mapping-drafts/{id}/confirm`：具体内容确认后只批准研究用途。24 小时过期、旧版本、未知身份/起始/复利方法拒绝批准。确认凭据不写日志或长期文件。
- `POST /v1/benchmark-research-preview`：纯计算，数据库不变。
- `POST /v1/benchmark-research-runs`：保存输入、证据、映射版本和确定性结果，可幂等重读；未批准映射仍可用于明确标注的隔离研究。
- HTTP 响应丢失先按基金读取及核对请求键；不盲目创建新版本。

## 历史与收益口径

组合成分明确发行方、代码、币种、价格/全收益/发布指数口径、权重、证据与可得性。有效区间含末日；未知原始生效日保留空值。观测日期不能当作政策生效日。研究覆盖起点须明确标为覆盖范围，不能冒充原始公告生效日。

每个相邻交易日收益按结束日选择适用权重，再逐日复利链接，不能将新权重追溯整段历史。调用方提交有来源的准确交易日网格；缺少任一端点、分红覆盖、指数日期、币种或口径时阻断计算，不前向填充、不猜汇率。

净值收益包含基金内部费用；现金分红按除息日再投资进行收益重建，不用累计净值当作复权价格，不再次扣管理费。已复权输入不能再加分红。个人申赎费用不在本研究口径内。

披露收益与序列重算分开输出，同区间按披露两位小数的舍入范围核对；超出范围保留差异警告。来自同一管理人的报告核对不是独立验证。最大回撤由本窗口财富路径计算；差额仅叫超额收益百分点，不能称选股 Alpha。至少二十个非恒定日收益才给相关性，相关性不证明归因。

现金利率必须先明确税收、计息和复利口径，原始利率不能冒充指数点位；外币指数须先有可验证的同币种序列。当前通用计算器对这些未解决输入明确阻断，不生成替代数字。

## 验收和后续

隔离测试覆盖历史权重、分红/费用、日历缺口、冲突/币种/口径、幂等并发、版本/过期治理、查询预览不变性、披露与重建分离及误差警告。真实资料与持仓级研究保存于私有验收目录并通过 Core 证据接口归档，不提交公共仓库。

八只基金候选表和重点案例以实际 Core 档案为准。未核实的指数变体、原始有效日、现金利率、汇率和独立来源继续保留缺口；风险阈值不自动补齐。账户截图、通知、C/D 影子模型、E 晋级及运行稳定性仍按唯一实施清单追踪。
